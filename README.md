# Uniway (MUJ Pathfinder) 🧭  
**Smart Campus Navigation for Manipal University Jaipur**

Uniway (also referred to as **MUJ Pathfinder**) is a student-built campus navigation platform designed to help students easily explore and navigate the Manipal University Jaipur campus.

Built **by students, for students**, Uniway focuses on accessibility, clarity, and real-time guidance across the university.

## 🌍 Problem Statement
The Manipal University Jaipur campus is large and dynamic, making navigation challenging—especially for new students.

Common issues include:
- Difficulty locating academic blocks, hostels, and facilities
- Lack of real-time, campus-specific navigation tools
- Limited accessibility-focused guidance

This often leads to confusion, wasted time, and unnecessary stress.

## 💡 Solution Overview
Uniway provides an **interactive campus navigation system** that enables students to move confidently across campus using real-time directions and intuitive maps.

The platform is designed to be:
- Easy to use
- Accurate
- Accessible for all users

## ⚙️ Core Features
Uniway offers:
- **Real-time location tracking** across campus
- **Turn-by-turn directions** to academic blocks, hostels, and facilities
- **Detailed digital campus maps** with landmarks
- **User-friendly interface** designed for quick navigation
- **Accessibility suggestions** for smoother campus movement
- **360-degree location views** via official map integrations

## 🛠️ Technology Overview
Uniway is built using modern web technologies:
- **Frontend:** React 18+, TypeScript, Vite
- **Mapping:** Leaflet with campus overlays
- **Styling:** Tailwind CSS, Lucide React
- **Core Web:** HTML5, CSS3, JavaScript (ES6+)
- **Tooling:** Node.js, npm, ESLint, Prettier
